## 🎯 What is Voxylis?

Voxylis is an AI-powered voice-to-text assistant that:

✅ **Records your voice** - Press a hotkey or say a wake word  
✅ **Transcribes to text** - Converts speech to text in 99+ languages  
✅ **Enhances text** - 5 modes: Formal, Casual, Technical, Concise, Creative  
✅ **Answers questions** - Live Q&A feature with instant answers  
✅ **Customizable** - Custom hotkeys, wake words, and settings  
✅ **Works everywhere** - Windows, macOS, Linux  
✅ **Beautiful interface** - Professional web dashboard  
✅ **Private** - All data stored locally

## 🚀 Getting Started

### For First-Time Users

1. **Install Python** (if not already installed)
   - Windows: https://www.python.org/downloads/
   - macOS: `brew install python3`
   - Linux: `sudo apt-get install python3`

2. **Install Dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run Voxylis**
   ```bash
   python start_voxylis.py
   ```

4. **Open Web Interface**
   - Go to: http://localhost:5000

5. **Configure Settings**
   - Set your language
   - Customize your hotkey
   - Set your wake word

6. **Start Recording**
   - Press your hotkey or say your wake word
   - Speak naturally
   - See your text appear!

## 🎮 How to Use

### Recording

**Method 1: Hotkey**
- Press Win+Shift (Windows) or Cmd+Shift (macOS)
- Speak your text
- Release to stop

**Method 2: Wake Word**
- Say "Voxy" (or your custom word)
- Voxylis starts listening
- Speak your text
- Say "Done" or wait 3 seconds

**Method 3: Click Widget**
- Click the minion widget
- Speak your text
- Click again to stop

### Enhancement

After recording, choose an enhancement mode:
- **Formal**: Professional tone
- **Casual**: Friendly style
- **Technical**: Precise terminology
- **Concise**: Short version
- **Creative**: Expanded version

### Q&A

1. Click "Ask a Question"
2. Type or speak your question
3. Get instant answer
4. Answer auto-hides after 5 seconds

## 🐛 Troubleshooting

### Python not found
- Install Python from https://www.python.org/downloads/
- Make sure to check "Add Python to PATH"

### Module not found
- Run: `pip install -r requirements.txt`

### Port 5000 already in use
- Close other applications using port 5000
- Or change port in web/app.py

### Microphone not detected
- Check if microphone is connected
- Go to Settings → Test Microphone
- Allow Voxylis to access microphone

### Web interface won't load
- Make sure Voxylis is running
- Try a different browser
- Clear browser cache
