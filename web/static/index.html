VX.0S3 · FAQ

Questions, answered

Is Voxylis free?

Yes — the Free plan includes 100 transcriptions a month, local history, and formal-mode enhancement. Pro and Business add quota, modes, and Q&A; paid plans are not purchasable in this deployment yet (see Pricing).

Where does my audio go?

To the speech provider whose key you configured (Groq or OpenAI) for transcription, and — only if you enable it — back for enhancement. Nothing else receives your audio. See Privacy for the full accounting.

Do I need an account?

No. Local dictation works without one. An account unlocks the web dashboard, history sync, and cloud transcription.

Which platforms are supported?

Windows 10/11 with a real installer. macOS and Linux run from source (Python 3.10+). See Download for details.

How is my data protected?

Transcripts live in a local SQLite database you can search, export, or delete. Provider keys live in the OS credential store, never in a settings file. There is no analytics and crash reporting is opt-in only.

Prefer the web?

Try the dashboard directly in your browser — no download needed.
