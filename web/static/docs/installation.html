Installation

Install Voxylis on Windows in a couple of minutes.

Recommended — installer
  1. Download Voxylis-Setup.exe from the download page.
  2. Run it. Installation is per-user by default, so no administrator prompt. A Start Menu shortcut is created; a desktop shortcut and "start when I sign in" are optional tasks.
  3. Launch Voxylis. The first-run wizard asks for your microphone, shortcut, language and an AI provider key.
  4. Press Win+Shift, speak, and your text lands in whatever app has focus.
From source (developers)
  1. Install Python 3.10+ (64-bit) and Git.
  2. git clone https://github.com/sumitagg24/Voxyai.git then cd voxyai.
  3. py -m pip install -r requirements.txt
  4. py main.py — the first-run wizard configures the rest.

Your settings, history and logs are written to %LOCALAPPDATA%\Voxylis, not into the source tree or the install directory. Provider API keys are stored in the OS credential store (DPAPI on Windows), never in a settings file.
