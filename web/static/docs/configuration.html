Configuration

Everything is configurable in the app under Settings.

Open the Voxylis window from the tray icon (double-click it, or choose Open Voxylis), then pick a section in the sidebar. Changes are saved immediately to %LOCALAPPDATA%\Voxylis\config\settings.json.

  • Home — recording state and controls, setup readiness (provider, microphone, shortcut, insertion, history), today's counters and the last error with a Details action.
  • History — search, export, delete individual entries, set retention or turn history off entirely.
  • Microphone — device picker, live level meter and a record/playback test.
  • AI Providers — paste a Groq or OpenAI key and choose the enhancement mode. Groq is preferred and used whenever its key is present; OpenAI is the fallback. Keys are stored in the OS credential store, not in settings.json.
  • Shortcuts — record a shortcut instead of typing one; reserved Windows combinations, duplicates and invalid keys are rejected.
  • Privacy — history retention, diagnostics export and full local-data deletion.
  • Account — optional sign-in, used only for the web dashboard.
  • Diagnostics — pipeline state, paths, recent errors and a redacted support bundle you can copy for a bug report.
  • About — version, licences and links.
settings.json fields (non-secret)
  • hotkey — global record shortcut, e.g. win+shift.
  • language — transcription language or auto.
  • enhancement_mode — formal, casual, technical, concise, creative or a custom mode.
  • mode_hotkeys — per-mode shortcuts, e.g. {"win+alt": "casual"}.
  • enable_ai_enhancement — rewrite transcripts before inserting them. Which provider is used follows from which key is stored in the vault (Groq first, then OpenAI).
  • auto_inject — type results into the focused application.
  • history_enabled, history_retention_days — local history controls.

Provider keys and session tokens are never written here.
