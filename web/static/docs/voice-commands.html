Voice Commands

Speak commands to trigger real actions.

Editing commands (applied to the text you just dictated)
  • clear that / delete that - remove the last insertion.
  • undo / undo that - undo the last action.
  • new line / next line - insert a line break.
  • new paragraph - insert a paragraph break.
  • select all, copy that, paste - standard clipboard actions.
  • caps lock - toggle caps lock for the next words.
  • translate it to <language> - translate the pending text.
  • stop / cancel - discard the current recording.
Rich commands

These are recognised only at the start of an utterance and are enabled by default (Settings → Microphone); an action that needs an integration you have not configured (for example Slack, which requires slack-sdk and a token in Settings → AI Providers) reports that clearly instead of failing silently.

  • search for ... / google search for ... - opens a web search in your browser.
  • create github issue ... - files an issue in the configured GITHUB_REPO (owner/repo).
  • draft email to ... about ... - drafts an email and copies it.
  • save ... as ... - stores a reusable snippet.
  • send slack message ... - posts to Slack when configured.
