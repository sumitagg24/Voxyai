Tips and Tricks

Get more out of Voxylis.

  • Use per-app profiles so chat apps get a casual tone while a document editor gets formal.
  • Define custom enhancement modes for repeated formats like standups or changelogs.
  • Bind different shortcuts to different modes (for example Win+Shift for default and Win+Alt for casual) and switch tone by muscle memory.
  • Turn on toggle mode if long dictation is easier than holding a key: press once to start, once to stop.
  • Set a history retention window in Settings → Privacy instead of clearing manually, and export to Markdown before a cleanup if you want to keep the text.
  • Optional: sign in on the Account page to sync usage stats and search history from the web dashboard. Local dictation never requires an account.
