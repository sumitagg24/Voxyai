Troubleshooting

Fix the most common issues.

  • No API key warning - add groq_api_key to config/settings.json.
  • Hotkey does nothing - run as administrator so the global listener can hook key events.
  • No microphone input - set audio_device to your mic index.
  • Empty transcription - recordings under 1 second or silence are skipped automatically.
