Troubleshooting

Fix the most common issues.

  • Provider authentication failed - the key was rejected. Settings → AI Providers → paste a valid key. Get a free one at console.groq.com/keys.
  • Hotkey does nothing - the shortcut may be taken by another application. Settings → Shortcuts → record a different combination. Reserved Windows shortcuts are rejected up front.
  • No microphone input - Settings → Microphone, pick the device and check the level meter while speaking.
  • Empty transcription - recordings shorter than a second, or silent ones, are skipped on purpose; you will see a "nothing was heard" notice, not an error.
  • Nothing is typed into the target app - some elevated windows (Task Manager, UAC prompts) reject synthetic input. Injection reports success only when the strategy actually completed, so you get an error rather than a silent loss; Diagnostics shows the last attempt. Also make sure the target window still had focus when you spoke.
  • Text was typed twice - the target application was slow to accept input. Voxylis blocks a duplicate injection while one is in flight; if a repeat still slips through, say undo or press Ctrl+Z in that application.
  • App will not start - another copy may already be running (Voxylis is single-instance). Logs are in %LOCALAPPDATA%\Voxylis\logs; Diagnostics → Copy diagnostics produces a redacted report with no keys or transcripts.
