Voxylis / About

Voice input, rethought

We believe the fastest way to get an idea out of your head is to say it out loud.

VX.0S1 · Mission

Typing is a bottleneck. Voice is often faster.

Voxylis is a small Windows dictation app. It listens while you hold a shortcut, sends the audio to the speech provider you configured, optionally asks a language model to tidy the result, and types the text into whatever window already has focus.

It is deliberately not a subscription lock-in: bring your own Groq or OpenAI key, or use browser dictation on the dashboard. Your transcripts live in a local database you control.

VX.0S3 · Values

What we believe

01

Honest limits

If a feature is not built yet, we say so. No invented user counts, ratings or accuracy figures.

02

Privacy by default

Audio goes only to the provider you configured. Transcripts stay in a local database, API keys live in the OS credential store, and history can be switched off or deleted at any time.

03

Works like code

Global hotkeys, per-app tone profiles and recorded shortcuts. Deterministic, inspectable, and yours to configure.

04

Ship, learn, repeat

The roadmap follows real bug reports and real usage. Releases are tagged in the public repository.
