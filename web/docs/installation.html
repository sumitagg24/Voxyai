Installation Guide

System Requirements

  • Windows: Windows 10 or later (64-bit)
  • macOS: macOS 10.14 or later
  • RAM: Minimum 4GB (8GB recommended)
  • Disk Space: 500MB free space
  • Microphone: Built-in, USB, or Bluetooth
  • Internet: Required for cloud transcription

Windows Installation

  1. Download the Windows installer from the download page
  2. Run VoxylisSetup.exe
  3. Follow the installation wizard
  4. Choose installation location (default: C:\Program Files\Voxylis)
  5. Select whether to add desktop shortcut
  6. Click "Install" and wait for completion
  7. Launch Voxylis from Start Menu or desktop shortcut

Portable Version (No Installation)

  1. Download Voxylis-portable.zip
  2. Extract to desired location
  3. Run Voxylis.exe directly
  4. No admin rights required

macOS Installation

  1. Download Voxylis.dmg from the download page
  2. Double-click to mount the disk image
  3. Drag Voxylis icon to Applications folder
  4. Open Applications folder and double-click Voxylis
  5. Grant microphone permissions when prompted
  6. Grant accessibility permissions for hotkey detection

First Launch

On first launch, macOS may show a security warning. Click "Open" to proceed.

Initial Setup

  1. API Key: Enter your Groq or OpenAI API key
  2. Microphone: Select your microphone from the list
  3. Language: Choose your default language
  4. Hotkey: Set your preferred hotkey (default: Win+Shift)
  5. Wake Word: Set custom wake word (default: "Voxy")

Getting an API Key

Groq (Recommended - Free)

  1. Visit console.groq.com/keys
  2. Sign up for a free account
  3. Create an API key
  4. Copy the key and paste in Voxylis settings

OpenAI (Paid)

  1. Visit platform.openai.com/api-keys
  2. Sign in or create account
  3. Create new API key
  4. Copy and paste in Voxylis settings

Troubleshooting Installation

Windows: "Cannot find Python"

Voxylis includes Python. If you see this error, try reinstalling.

macOS: "Cannot open Voxylis"

Right-click Voxylis and select "Open" to bypass security warning.

Microphone Not Detected

Check Windows/macOS audio settings and ensure microphone is enabled.

Uninstallation

Windows

  1. Go to Settings → Apps → Apps & features
  2. Find "Voxylis" in the list
  3. Click and select "Uninstall"
  4. Follow the uninstall wizard

macOS

  1. Open Applications folder
  2. Right-click Voxylis
  3. Select "Move to Trash"
