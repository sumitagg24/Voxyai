## 🔧 How to Use

### Start Recording
1. Click "🎤 Recording" in sidebar
2. Click "🔴 Start Recording" button
3. Speak into your microphone
4. Click "⏹️ Stop Recording"
5. See transcription appear
6. Choose enhancement mode
7. Copy or save

### Ask a Question
1. Click "❓ Q&A" in sidebar
2. Type your question
3. Click "🚀 Ask"
4. Get instant answer
5. View question history

### Configure Settings
1. Click "⚙️ Settings" in sidebar
2. Change language, wake word, hotkey, theme
3. Adjust sensitivity slider
4. Enable/disable features
5. Click "💾 Save Settings"

### View History
1. Click "📜 History" in sidebar
2. Search for recordings
3. Export as text/PDF
4. Delete old recordings
5. Clear all history

## 📊 API Endpoints (Web)

All endpoints are working:

```
GET  /api/health          - Health check
GET  /api/features        - Get features
GET  /api/pricing         - Get pricing tiers
GET  /api/settings        - Get settings
POST /api/settings        - Update settings
GET  /api/hotkeys         - Get hotkeys
POST /api/hotkeys         - Update hotkeys
POST /api/qa              - Ask question
GET  /api/history         - Get history
POST /api/history         - Add recording
DELETE /api/history       - Delete recording
GET  /api/stats           - Get statistics
GET  /api/subscription    - Get subscription
POST /api/subscription    - Update subscription
```
